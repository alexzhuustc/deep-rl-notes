# 元强化学习（meta-RL）有没有好上手的源代码？

作者：ZyBird · 保存：2026-11-10 · 原文更新：2022-05-11  
来源：[https://www.zhihu.com/question/532325016/answer/2482134268](https://www.zhihu.com/question/532325016/answer/2482134268)

[知识库首页](../../README.md)

---

1. PEARL:

[GitHub - katerakelly/oyster: Implementation of Efficient Off-policy Meta-learning via Probabilistic Context Variables (PEARL)](https://github.com/katerakelly/oyster)

lamda组复现的简洁版PEARL，性能与官方实现相同：

<https://github.com/x35f/meta_rl/tree/0b7372c46bbc32a4d3b8459aa62131e47ef27bce>

2. MQL:

<https://github.com/amazon-research/meta-q-learning>

PEARL是基于rlkit库，MQL基于PEARL，两种算法代码写的都非常优雅，个人感觉比较容易上手，希望对你有所帮助~

ps：PEARL和MQL配置环境的时候需要使用mujoco131和mujoco200；两者都需要下载并放在~/.mujoco目录下，方可运行；mujoco131不需要安装，但是200需要pip install；不能使用最新的mujoco版本运行这两个代码；
