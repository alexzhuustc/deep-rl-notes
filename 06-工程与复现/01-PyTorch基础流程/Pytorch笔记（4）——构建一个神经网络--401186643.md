神经网络（Neural networks）包含处理数据所需要的层与模块，`torch.nn`命名空间提供了构建神经网络所需要的所有板块。Pytorch中的所有模块均属于`nn.Module`的子类，而神经网络自身就是一个由其他模块（层）所组成的模块，这种嵌套结构使得我们能够轻易地构建和管理复杂的框架。

在接下来的章节中，我们将基于FashionMINIST数据集构建一个用于图像分类的神经网络。

```
import os
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
```

### **获取训练设备（Get Device for Training）**

我们希望我们的模型能够在GPU等硬件加速器上训练，因此我们首先需要检查`torch.cuda`是否存在，如果不存在则继续使用CPU。

```
device = 'cuda' if torch.cuda.is_available() else 'cpu'
print('Using {} device'.format(device))
```

Out:

```
Using cuda device
```

### **定义类（Define the Class）**

我们首先需要定义一个`nn.Module`子类的神经网络，然后再`__init__`中初始化神经网络的层。每个`nn.Module`子类都在`forward`方法中对输入数据执行操作。

```
class NeuralNetwork(nn.Module):
    def __init__(self):
        super(NeuralNetwork, self).__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28*28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
            nn.ReLU()
        )
​
    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits
```

然后我们可以创建`NeuralNetwork`的一个实例，并将其转移到`device`上，还可以打印其结构。

```
model = NeuralNetwork().to(device)
print(model)
```

Out:

```

  (flatten): Flatten(start_dim=1, end_dim=-1)
  (linear_relu_stack): Sequential(
    (0): Linear(in_features=784, out_features=512, bias=True)
    (1): ReLU()
    (2): Linear(in_features=512, out_features=512, bias=True)
    (3): ReLU()
    (4): Linear(in_features=512, out_features=10, bias=True)
    (5): ReLU()
  )
)
```

将输入数据传递给模型，这时模型会自动执行`forward`方法以及一些其他后台操作，记住：**不要直接调用`model.forward()`**。

在输入数据上调用模型会返回一个10-维的张量，这个张量包含了每个类别的预测值，我们将其传递给`nn.Softmax`以获得不同类别的预测概率。

```
X = torch.rand(1, 28, 28, device=device)
logits = model(X)
pred_probab = nn.Softmax(dim=1)(logits)
y_pred = pred_probab.argmax(1)
print(f"Predicted class: {y_pred}")
```

Out:

```
Predicted class: tensor([2], device='cuda:0')
```

### **层建模（Model Layers）**

将FashionMINIST模型分解，然后将一个由3个28\times​​​​28的图像组成的小批次输入到网络中看看会发生些什么。

```
input_image = torch.rand(3,28,28)
print(input_image.size())
```

Out:

```
torch.Size([3, 28, 28])
```

### **nn.Flatten**

初始化`nn.Flatten`层，将2D的28\times28图像转换成一个由784个像素值组成的连续数组（小批次所在的维度（dim=0）维持不变）。

```
flatten = nn.Flatten()
flat_image = flatten(input_image)
print(flat_image.size())
```

Out:

```
torch.Size([3, 784])
```

### **nn.Linear**

线性层（linear layer）利用其权重（weights）与偏置（bias）对输入进行线性变换。

```
layer1 = nn.Linear(in_features=28*28, out_features=20)
hidden1 = layer1(flat_image)
print(hidden1.size())
```

Out:

```
torch.Size([3, 20])
```

### **nn.ReLU**

在我们的模型中，我们使用`nn.ReLU`连接线性层，实际上还有一些其他的激活函数可以用于引入非线性。

### **nn.Sequential**

`nn.Sequential`是模块的有序容器，数据会根据所定义的次序依次通过各个模块，因此我们可以利用容器迅速搭建起一个网络。

```
seq_modules = nn.Sequential(
    flatten,
    layer1,
    nn.ReLU(),
    nn.Linear(20, 10)
)
input_image = torch.rand(3,28,28)
logits = seq_modules(input_image)
```

### **nn.Softmax**

神经网络的最后一个线性层返回*logits*——[-infty,infty]内的原始值，然后将其传递给`nn.Softmax`模块，此时logits会映射到[0,1]区间，以此表示模型所得到的每个类别的预测概率。`dim`参数表示数据变换所沿着的维度。

```
softmax = nn.Softmax(dim=1)
pred_probab = softmax(logits)
```

### **模型参数**

神经网络中的许多层都包含参数，即包含相互连接的权重与偏置，这些参数在训练中得到优化。子类`nn.Module`会自动跟踪模型对象中的所有参数，并通过模型的`parameters()`与`named_parameters()`方法返回参数。

在本例中，我们在每个参数上进行迭代，并打印出它们的尺寸和值的预览。

```
print("Model structure: ", model, "\n\n")
​
for name, param in model.named_parameters():
    print(f"Layer: {name} | Size: {param.size()} | Values : {param[:2]} \n")
```
