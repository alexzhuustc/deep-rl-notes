既然我们已经有了模型与数据，那么我们就需要利用数据对模型参数进行优化，从而实现模型的训练、验证以及测试等过程。模型的训练时一个迭代的过程：在每一次迭代中（一个**epoch**），模型输出一个预测值，同时计算该预测值的损失，并收集该损失对于模型参数的导数，最后利用梯度下降法**优化**这些参数。

### **先决条件代码**

首先总结前面几章的代码。

```
import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import ToTensor, Lambda
​
training_data = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=ToTensor()
)
​
test_data = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=ToTensor()
)
​
train_dataloader = DataLoader(training_data, batch_size=64)
test_dataloader = DataLoader(test_data, batch_size=64)
​
class NeuralNetwork(nn.Module):
    def __init__(self):
        super(NeuralNetwork, self).__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28*28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10),
            nn.ReLU()
        )
​
    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits
​
model = NeuralNetwork()
```

### **超参数（Hyperparameters）**

超参数（Hyperparameters）是可用于控制模型优化过程的可调参数，不同的超参数值会影响模型训练的收敛速率（详情见[超参数调参](https://pytorch.org/tutorials/beginner/hyperparameter_tuning_tutorial.html)）。

定义如下超参数：

- **迭代次数（Number of Epochs）**——在数据集上迭代的次数
- **批数量（Batch Size）**——参数更新之前传递给网络的样本数
- **学习率（Learning Rate）**——在每个batch/epoch中模型参数的更新程度，值越小学习速率越慢，当值很大时可能造成不可预测的行为

```
learning_rate = 1e-3
batch_size = 64
epochs = 5
```

### **优化过程（Optimization Loop）**

当我们设置好超参数之后，我们就可以在一次优化过程中训练并优化我们的模型了，每一次优化被称为一个**epoch**。

每一个epoch主要由两个部分组成：

- **训练（Train）部分**——通过在训练数据集上迭代试图收敛到最优参数
- **验证（Validation）/测试（Test）部分**——通过在测试集上迭代检查模型的性能是否有所提升

### **损失函数（Loss Function）**

当给定一些训练数据时，未训练的网络无法给出正确的结果。**损失函数（Loss function）**可以用于度量模型输出与目标结果值之间的差异程度，这也是我们在训练过程中需要优化的指标。为了计算损失函数，我们首先计算一个给定数据样本的预测值，然后将其与真实的数据标签值进行比较。

常见的损失函数包括用于回归任务的`nn.MSELoss`（均方误差），用于分类的`nn.NLLoss`（负对数似然），而`nn.CrossEntropyLoss`（交叉熵函数）则是`nn.LogSoftmax`与`nn.NLLLoss`的结合。

```
# Initialize the loss function
loss_fn = nn.CrossEntropyLoss()
```

### **优化器（Optimizer）**

优化是训练中对模型参数进行调整从而减少模型误差的过程，**优化算法**决定了这一过程如何进行。所有的优化逻辑都被内嵌在`optimizer`对象中。这里，我们使用SGD（Stochastic Gradient Descent，随机梯度下降）优化器，实际上，Pytorch中由许多不同的优化器，例如ADAM与RMSProp，它们对于不同种类的模型与数据表现更为优异。

为了初始化优化器，首先需要记录需要训练的模型参数，同时还要传递学习率这一超参数。

```
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)
```

在训练过程中，优化的过程总共有三个步骤：

- 调用`optimizer.zero_grad()`重置模型参数的梯度。默认情况下，梯度会依次增加，为了防止多次累加，我们需要在每次迭代时将它们清零。
- 调用`loss.backwards()`反向传播预测损失。Pytorch会将损失函数对于每个参数的梯度存储起来。
- 计算得到梯度之后，调用`optimizer.step()`调整模型参数。

### **完整操作**

定义`train_loop`来实现我们的优化代码，而`test_loop`则用于评估模型对于测试数据的性能。

```
def train_loop(dataloader, model, loss_fn, optimizer):
    size = len(dataloader.dataset)
    for batch, (X, y) in enumerate(dataloader):
        # Compute prediction and loss
        pred = model(X)
        loss = loss_fn(pred, y)
​
        # Backpropagation
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
​
        if batch % 100 == 0:
            loss, current = loss.item(), batch * len(X)
            print(f"loss: {loss:>7f}  [{current:>5d}/{size:>5d}]")
​
​
def test_loop(dataloader, model, loss_fn):
    size = len(dataloader.dataset)
    num_batches = len(dataloader)
    test_loss, correct = 0, 0
​
    with torch.no_grad():
        for X, y in dataloader:
            pred = model(X)
            test_loss += loss_fn(pred, y).item()
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()
​
    test_loss /= num_batches
    correct /= size
    print(f"Test Error: \n Accuracy: {(100*correct):>0.1f}%, Avg loss: {test_loss:>8f} \n")
```

初始化损失函数与优化器，然后将它们传递给`train_loop`与`test_loop`。

```
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=learning_rate)
​
epochs = 10
for t in range(epochs):
    print(f"Epoch {t+1}\n-------------------------------")
    train_loop(train_dataloader, model, loss_fn, optimizer)
    test_loop(test_dataloader, model, loss_fn)
print("Done!")
```
