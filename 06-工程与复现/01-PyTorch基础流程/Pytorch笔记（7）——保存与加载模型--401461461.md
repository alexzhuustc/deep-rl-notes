### **保存与加载模型权重**

Pytorch的模型会将学习到的参数保存在一个内置的状态字典里，名为`state_dict`，该字典可以通过`torch.save`方法保存：

```
model = models.vgg16(pretrained=True)
torch.save(model.state_dict(), 'model_weights.pth')
```

如果要加载模型参数，我们首先需要创建一个相同模型的实例，然后使用`load_state_dict()`方法加载参数。

```
model = models.vgg16() # we do not specify pretrained=True, i.e. do not load default weights
model.load_state_dict(torch.load('model_weights.pth'))
model.eval()
```

---

注意

一定要在推理之前调用`model.eval()`方法将dropout和批量归一化（batch normalization）调为评估模式，否则会产生不连续的推理结果。

---

### **保存与加载完整模型**

在加载模型权重时，我们首先需要创建一个模型类的实例，这个类决定了网络的结构。实际上，我们也可以直接保存模型的完整结构，此时我们需要将`model`传递给函数：

```
torch.save(model, 'model.pth')
```

加载模型时使用：

```
model = torch.load('model.pth')
```
