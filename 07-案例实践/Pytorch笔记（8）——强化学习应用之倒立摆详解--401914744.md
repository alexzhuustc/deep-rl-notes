本章将以倒立摆（CartPole-v0）任务为例，展示如何利用Pytorch训练深度Q学习（Deep Q Learning，DQN）智能体。

- 倒立摆是一个存在终止状态的游戏，因此在这个游戏中，从初始状态到游戏结束为一个episode。
- 由于在Gym中已经有设计好的倒立摆环境，所以在本节主要学习训练过程，而不关注环境的搭建。

### **任务**

智能体需要在两个动作中进行选择——向左移动还是向右移动——使得小车上的杆能够保持直立，关于该任务的各种算法及其性能对比请见[Gym website](https://gym.openai.com/envs/CartPole-v0)，

![](../assets/images/5d8d441568ff5b0c175a.jpg)

在每一时刻，智能体观测环境的当下状态并选择一个动作，这会导致环境转移到一个新的状态，与此同时环境会返回给智能体一个奖励，该奖励反映了动作所导致的结果。在倒立摆任务中，每一个时间步的奖励均为+1，但是一旦小车偏离中心超过4.8个单位或者杆的倾斜超过15度，任务就会终止。因此，我们的目标是使得该任务能够尽可能地运行得更久，以便获得更多的收益。

原始倒立摆任务中，智能体的输入包含4个实数（位置，速度等），但实际上，神经网络可以直接通过观察场景来完成任务，所以我们可以直接使用以小车为中心的屏幕补丁作为输入。严格来说，我们设计的状态是当前屏幕补丁与上一个屏幕补丁的差值，这使得智能体能够从一张图像中推断出杆的速度。

### **记忆回放（Replay Memory）**

为了训练DQN，我们将使用**经验回放池（experience replay memory）**来存储智能体所观测到的环境状态转移情况，在之后的训练中我们可以充分利用这些数据。通过对经验回放池中的数据进行随机采样，组成一个批次的转移情况是互不相关（decorrelated）的，这极大地提升了DQN训练的性能和稳定性。

为此，我们需要以下两个实例：

- 转移（`Transition`）——1个表示单个环境状态转移的命名元组，它将（状态，动作）对映射到（下一个状态，奖励）上。
- 记忆回放（`ReplayMemory`）——一个用于存放近期环境转移的有限尺寸循环缓存区，它提供了`.sample`方法来选择训练所需的随机批次转移。

```
Transition = namedtuple('Transition',
                        ('state', 'action', 'next_state', 'reward'))
​
​
class ReplayMemory(object):
​
    def __init__(self, capacity):
        self.memory = deque([],maxlen=capacity)
​
    def push(self, *args):
        """Save a transition"""
        self.memory.append(Transition(*args))
​
    def sample(self, batch_size):
        return random.sample(self.memory, batch_size)
​
    def __len__(self):
        return len(self.memory)
```

---

- **命名元组**

```
collections.namedtuple(typename, field_names, *, rename=False, defaults=None, module=None)
```

返回一个名为`typename`（例如`Transition`）的元组子类，`field_name`是一系列字符串，例如`('state', 'action', 'next_state', 'reward')`，在上述代码中，对`Transition`实例化之后，就可以通过字典索引或位置索引给每个字符串对应的元素赋值。

- **双端队列**

```
collections.deque([iterable[, maxlen]])
```

返回一个从左至右初始化的新双端队列对象，该队列包含的数据为可迭代对象。如果`iterable`没有定义，则新的队列为空。`maxlen`表明队列的最大长度。一旦有界长度的双端队列已满，当添加新元素时，从另一端丢弃相应数量的元素。

- **随机采样**

```
random.sample(population, k, *, counts=None)
```

返回从总体序列或集合 `population` 中选择的唯一元素的 `k` 长度列表,用于不放回的随机抽样。

### **DQN算法**

我们的环境是确定性的，所以为了表达的简洁性，这里的所有方程都表示成确定性的，在强化学习领域，它们也可以表示环境的随机变化。

我们训练策略的目标是最大化收益，在这里收益定义为无折扣累积奖励 $R_{t_{0}}=\sum_{t=t_{0}}^{\infty} \gamma^{t-t_{0}} r_{t}$ ，其中折扣因子 是一个 0 到 1 之间的常量，它保证了求和的收敛性，同时降低了未来时刻奖励的重要性。

Q-learning背后的主要思想是如果我们知道状态与动作到收益之间的映射，也就是函数 Q^{*}:State \times Action \rightarrow \mathbb{R}​​，那么我们就知道在给定状态下应该如何选取动作使得收益最大，此时策略可以写为



$$
\pi^{*}(s)=\operatorname{argmax}_{a} Q^{*}(s, a)
$$



然而，我们并不知道如何计算 Q^*​，幸运的是，根据神经网络的万能近似理论，我们可以创建一个神经网络并用它来模拟 Q^*。

我们可以基于最优贝尔曼方程对神经网络进行更新：

等式两边的差被称为时间差分误差，



$$
\delta=Q^{*}(s, a)-(r+\gamma \max_a Q^{*}\left(s^{\prime}, \pi\left(s^{\prime}\right)\right))
$$



为了最小化误差，我们使用休伯损失（Hubert loss）。当误差很小时，休伯损失即为均方误差（ mean squared error），但是当误差很大时，休伯损失就变成了平均绝对误差（mean absolute error），当 Q 的估计包含许多噪声时，休伯损失对于异常的鲁棒性更大。我们根据从经验回放池中采样得到的一个批次的环境转移值，B，来计算损失函数：



$$
\begin{gathered} \mathcal{L}=\frac{1}{|B|} \sum_{\left(s, a, s^{\prime}, r\right) \in B} \mathcal{L}(\delta) \\ \text { where } \mathcal{L}(\delta)= \begin{cases}\frac{1}{2} \delta^{2} & \text { for }|\delta| \leq 1 \\ |\delta|-\frac{1}{2} & \text { otherwise }\end{cases} \end{gathered}
$$



由于 $(r+\gamma \max_a Q^{*}\left(s^{\prime}, \pi\left(s^{\prime}\right)\right)) $ 同样与神经网络参数有关，会造成训练的不稳定，因此我们可以通过另一个目标网络来对该表达式进行拟合，目标网络的参数每隔一段时间从主网络复制而来。​

### **Q-网络**

我们的模型是一个卷积神经网络，输入为当下屏幕补丁与上一时刻屏幕补丁的差值，输出有两个，分别为 $Q(s,\text{left}) $ 与 $Q(s,\text{right})$ （ s​ 为网络的输入），在这样的情况下，模型训练的目标是预测给定输入下执行每一动作所对应的期望收益。

```
class DQN(nn.Module):
​
    def __init__(self, h, w, outputs):
        super(DQN, self).__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=5, stride=2)
        self.bn1 = nn.BatchNorm2d(16)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=5, stride=2)
        self.bn2 = nn.BatchNorm2d(32)
        self.conv3 = nn.Conv2d(32, 32, kernel_size=5, stride=2)
        self.bn3 = nn.BatchNorm2d(32)
​
        # Number of Linear input connections depends on output of conv2d layers
        # and therefore the input image size, so compute it.
        def conv2d_size_out(size, kernel_size = 5, stride = 2):
            return (size - (kernel_size - 1) - 1) // stride  + 1
        convw = conv2d_size_out(conv2d_size_out(conv2d_size_out(w)))
        convh = conv2d_size_out(conv2d_size_out(conv2d_size_out(h)))
        linear_input_size = convw * convh * 32
        self.head = nn.Linear(linear_input_size, outputs)
​
    # Called with either one element to determine next action, or a batch
    # during optimization. Returns tensor([[left0exp,right0exp]...]).
    def forward(self, x):
        x = x.to(device)
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.relu(self.bn2(self.conv2(x)))
        x = F.relu(self.bn3(self.conv3(x)))
        return self.head(x.view(x.size(0), -1))
```

```
    # Returned screen requested by gym is 400x600x3, but is sometimes larger
    # such as 800x1200x3. Transpose it into torch order (CHW).
    screen = env.render(mode='rgb_array').transpose((2, 0, 1))
    # Cart is in the lower half, so strip off the top and bottom of the screen
    _, screen_height, screen_width = screen.shape
    screen = screen[:, int(screen_height*0.4):int(screen_height * 0.8)]
    view_width = int(screen_width * 0.6)
    cart_location = get_cart_location(screen_width)
    if cart_location < view_width // 2:
        slice_range = slice(view_width)
    elif cart_location > (screen_width - view_width // 2):
        slice_range = slice(-view_width, None)
    else:
        slice_range = slice(cart_location - view_width // 2,
                            cart_location + view_width // 2)
    # Strip off the edges, so that we have a square image centered on a cart
    screen = screen[:, :, slice_range]
    # Convert to float, rescale, convert to torch tensor
    # (this doesn't require a copy)
    screen = np.ascontiguousarray(screen, dtype=np.float32) / 255
    screen = torch.from_numpy(screen)
    # Resize, and add a batch dimension (BCHW)
    return resize(screen).unsqueeze(0)
```

### **训练过程**

本节介绍训练所需的代码。

定义`optimize_model`函数用于执行一个时间步的优化，主要步骤如下：

1. 采样得到一个批次的样本，将这些样本对应的张量连接成一个单独的张量；
2. 分别利用策略Q网络与目标Q网络计算 $Q(s_t,a_t)​​​​ 与 V(s_{t+1})=\max_aQ(s_{t+1},a)$ ​​​​，利用它们计算损失函数.。另外，如果 $s​​​​$ 为终止状态，则令 $V(s)=0$ ​​​​
3. 更新Q网络参数。目标Q网络的参数每隔一段时间从主Q网络处固定而来，在本例中，我们在每个episode更新一次目标Q网络。

### **一次更新**

```
def optimize_model():
    if len(memory) < BATCH_SIZE:
        return
    transitions = memory.sample(BATCH_SIZE)
    # Transpose the batch (see https://stackoverflow.com/a/19343/3343043 for
    # detailed explanation). This converts batch-array of Transitions
    # to Transition of batch-arrays.
    batch = Transition(*zip(*transitions))
​
    # Compute a mask of non-final states and concatenate the batch elements
    # (a final state would've been the one after which simulation ended)
    non_final_mask = torch.tensor(tuple(map(lambda s: s is not None,
                                          batch.next_state)), device=device, dtype=torch.bool)
    non_final_next_states = torch.cat([s for s in batch.next_state
                                                if s is not None])
    state_batch = torch.cat(batch.state)
    action_batch = torch.cat(batch.action)
    reward_batch = torch.cat(batch.reward)
​
    # Compute Q(s_t, a) - the model computes Q(s_t), then we select the
    # columns of actions taken. These are the actions which would've been taken
    # for each batch state according to policy_net
    state_action_values = policy_net(state_batch).gather(1, action_batch)
​
    # Compute V(s_{t+1}) for all next states.
    # Expected values of actions for non_final_next_states are computed based
    # on the "older" target_net; selecting their best reward with max(1)[0].
    # This is merged based on the mask, such that we'll have either the expected
    # state value or 0 in case the state was final.
    next_state_values = torch.zeros(BATCH_SIZE, device=device)
    next_state_values[non_final_mask] = target_net(non_final_next_states).max(1)[0].detach()
    # Compute the expected Q values
    expected_state_action_values = (next_state_values * GAMMA) + reward_batch
​
    # Compute Huber loss
    criterion = nn.SmoothL1Loss()
    loss = criterion(state_action_values, expected_state_action_values.unsqueeze(1))
​
    # Optimize the model
    optimizer.zero_grad()
    loss.backward()
    for param in policy_net.parameters():
        param.grad.data.clamp_(-1, 1)
    optimizer.step()
```

- 将`batch`中的`state`,`action`,`next_states`,`reward`分别取出，各自组成一个`batch`

```
    # Compute a mask of non-final states and concatenate the batch elements
    # (a final state would've been the one after which simulation ended)
    non_final_mask = torch.tensor(tuple(map(lambda s: s is not None,
                                          batch.next_state)), device=device, dtype=torch.bool)
    non_final_next_states = torch.cat([s for s in batch.next_state
                                                if s is not None])
    state_batch = torch.cat(batch.state)
    action_batch = torch.cat(batch.action)
```

```
    # columns of actions taken. These are the actions which would've been taken
```

- 计算 $V(s_{t+1})=\max_aQ(s_{t+1},a)$ ​

```
    # Compute V(s_{t+1}) for all next states.
    # Expected values of actions for non_final_next_states are computed based
    # on the "older" target_net; selecting their best reward with max(1)[0].
    # This is merged based on the mask, such that we'll have either the expected
    # state value or 0 in case the state was final.
    next_state_values = torch.zeros(BATCH_SIZE, device=device)
    next_state_values[non_final_mask] = target_net(non_final_next_states).max(1)[0].detach()
    # Compute the expected Q values
    expected_state_action_values = (next_state_values * GAMMA) + reward_batch
```

---

`Tensor.detach()`返回一个新的 Tensor，与当前图形分离，不计算梯度。

---

上述代码首先初始化了一个全零的V(s_{t+1}) $V(s_{t+1})$ 即`next_state_values`，利用`target_net`计算所有非终止状态的 $Q(s_{t+1},a)$ ，在 $a$ 上取最大值得到 $V(s_{t+1})=\max_aQ(s_{t+1},a)$ ，然后利用`non_final_mask`作为索引，将得到的结果赋值给`next_state_values`。

最后，利用公式 $Q^{*}(s, a)=r+\gamma \max_a Q^{*}\left(s^{\prime}, \pi\left(s^{\prime}\right)\right)$ 计算得到期望Q值`expected_state_action_values`。

### **完整训练**

训练的完整过程有以下几个步骤：

1. 重置环境，初始化`state`；
2. 执行一个动作，观测下一个状态和奖励；
3. 参数更新；
4. 重复2、3；
5. 当任务终止时，重新开始1.
