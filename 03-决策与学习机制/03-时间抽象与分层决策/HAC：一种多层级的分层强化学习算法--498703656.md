与[HIRO](HIRO：一种off-policy的分层强化学习算法--497424021.md)一样，本文解决的同样是分层强化学习中不同层级策略学习所存在的非平稳问题，但是用了完全不同思想的方法。另外，HAC可以看做是[HER](../02-记忆探索与目标条件/Hindsight Experience Replay（HER）：一种对抗稀疏奖励的经验回放技术--501043736.md)在分层结构中的扩展。

分层强化学习通过将任务分解成多个子任务，样本利用率更高。然而，在分层结构中，上层的转移函数取决于下层的策略，当所有层级的策略同时进行训练时，下层策略不断更新，这就导致了上层的转移函数会随之不断变化，在这样的非平稳环境中，智能体很难学习到最优策略，这就是分层强化学习所面临的**非平稳（non-stationary）**问题。当前大多数分层强化学习算法一次只能训练一个层级，为了**并行地训练多个层级**，本论文的主要思路是：当下层的任务收敛到最优或次优时，上层策略就可以进行稳定训练了。基于这一思想，本文提出了**Hierarchical Actor-Critic (HAC)，**主要创新点是设计了三种transition样本用于训练。

## **算法背景**

本文构建了一个 **万能马尔科夫决策过程（Universal Markov Decision Process，UMDP）**，UMDP在MDP的基础上引入了 **目标（goals）** 的集合，在本文中，目标指代的是我们希望智能体所能达到的 **状态（states）**。一个UMDP可以用 $\mathcal{U}=(\mathcal{S},\mathcal{G},\mathcal{A},T,R,\gamma)$，其中 $\mathcal{S}$ 为状态的集合，$\mathcal{G}$ 为目标的集合，$\mathcal{A}$ 为动作的集合，$T$ 为状态转移函数（$T(s,a,s')$ 为状态转移概率），$R$ 为奖励函数，$\gamma$ 为折扣因子。在UMDP中每个episode的开始，会选择一个 $g\in\mathcal{G}$ 作为整个episode的目标。UMDP的目标是得到一个策略 $\pi:  \mathcal{S},\mathcal{G}\rightarrow\mathcal{A}$，该策略能够最大化价值函数 $v_{\pi}(s, g)=\mathbb{E}_{\pi}\left[\sum_{n=0}^{\infty} \gamma^{n} R_{t+n+1} \mid s_{t}=s, g_{t}=g\right]$。

HAC中使用了RL领域中的两个技术：

- **Universal Value Function Approximator（UVFA）**：UVFA用于学习目标驱动策略 $\pi$ 的动作-状态价值函数 $q_\pi(s,g,a)=\mathbb{E}_{\pi}\left[\sum_{n=0}^{\infty} \gamma^{n} R_{t+n+1} \mid s_{t}=s, g_{t}=g, a_{t}=a\right]$。实际上，UVFA一类迁移强化学习算法，它可以将 $(state,goal,action)$ 空间中特定区域的Q值迁移到该空间的其他区域，从而加速学习。
- **Hindsight Experience Replay（HER）**：HER是用来应对稀疏奖励问题的数据增强技术，该技术通过复制传统off-policy RL中产生的样本 $[state,action,reward,next\ state,goal]$，然后将其中的目标换成当前episode中已经完成的状态，保证了HER中总有样本能够获得系数奖励，从而达到加速学习的目的。

## **算法介绍**

HAC包含两部分：1）一个特定的分层结构；2）一种能够同时且独立训练各层级策略的方法。HAC的目标是高效地学习一个 $k$ 级层级结构 $\Pi_{k-1}$，该结构包含 $k$ 个独立的策略 $\pi_0...\pi_k$，其中 $k$ 是超参数。为了并行地学习 $\pi_0...\pi_k$，本框架将原始的UMDP $\mathcal{U}_{original}=(\mathcal{S},\mathcal{G},\mathcal{A},T,R,\gamma)$ 转换成 $k$ 个UMDP $\mathcal{U}_0,...,\mathcal{U}_{k-1}$，其中 $\mathcal{U}_{i}=\left(\mathcal{S}_{i}, \mathcal{G}_{i}, \mathcal{A}_{i}, T_{i}, R_{i}, \gamma_{i}\right)$。

### **状态，目标与动作空间**

对于每个层级，状态空间，目标空间以及最底层以上的动作空间均与原始状态空间相同：$\mathcal{S}_i=\mathcal{S}$，$\mathcal{G}_i=\mathcal{S}$，$\mathcal{A}_i=\mathcal{S}$（$i>0$）。每一层输出的动作即为下一层的目标。最底层的动作空间为原始动作空间：$\mathcal{A}_0=\mathcal{A}$。

### **Nested Policies**

HAC 通过将 $i-1$ 层的策略 $\pi_{i-1}$ 嵌入到第 $i$ 层的转移函数 $T_i$ 实现了策略之间的嵌套：第 $i$ 层选择的subgoal动作 $a_i$ 指定了第 $i-1$ 层的目标：$g_{i-1}=a_i$，然后 $\pi_{i-1}$ 会进行不超过 $H$ 次尝试来实现 $g_{i-1}$，这里 $H$ 是一个超参数，一旦尝试次数超过 $H$ 或者第 $i-1$ 层达到了目标状态，转移函数就会终止，然后返回当前状态。由此可以看出，分层嵌套结构使得第 $i$ 层的状态转移函数取决于第 $i$ 层一下的所有策略 $\Pi_{i-1}$。因此，我们用 $T_{i|\Pi_{i-1}}$ 来表示第 $i$ 层的状态转移函数。

### **Hindsight Action Transitions**

在分层强化学习中，造成转移函数非平稳性的原因有两个：1）低层策略的不断更新；2）低层策略为了探索而采用行为策略（behavior policy），例如确定性策略中，在生成的动作上加入额外的噪声。为了克服非平稳性，HAC在训练每一层策略时，假设下层策略是最优的，即 $\Pi_{i-1}^*$。$\Pi_{i-1}^*$ 独立于变化或者探索中的下层策略，因此是平稳的。

![](../../assets/images/5c7830dfa6899967362c.jpg)

简单来说，Hindsight action transitions包含两个重要组成部分（transition表示一个状态转移元组）：

- transition中的action是事后已经达到的状态，而非之前所提出的subgoal状态。
- transition中的reward只与目标以及事后达到的状态有关，即如果goal没有达到，奖励就为-1，达到了就为0。

以上图中所展示的两层任务为例，其中上层任务在 $s_1$ 时的 Hindsight action transitions为：$[initial\ state=s_0,action=s_1,reward=0,next\ state=s_1,goal=yellow\ flag,discount\ rate =gamma]$

（原本的动作是 $g_0$，由于智能体事后到达了状态 $s_1$，所以将动作改为了 $s_1$）这一转移达到的效果与高层策略选择 $s_1$ 作为目标且下层策略是最优策略时达到的效果一致。

尽管这些hindsight action均不能获得稀疏奖励，它们对智能体的上层训练依然是有帮助的，因为它们能够帮助高层策略找到 $H$ 个原始动作所能达到的目标。并且，这些transitions都能够克服下层策略变化或者探索产生的影响。

### **Hindsight Goal Transitions**

为了**解决稀疏奖励问题**，本文还提出补充另一组transitions——hindsight goal transitions。Hindsight goal transitions 实际上就是将 Hindsight Experience Replay 扩展到了分层结构中，保证了每一层级均能在一段动作之后获得一个稀疏奖励。简单来说，Hindsight goal transitions 就是在每隔一段transitions序列之后，在这一些transitions中选择一个所达到的 $next\ state$ 作为当前层级的goals，这样就能保证一定会有一个transitions的reward是有效的。

依然以上图中的上层策略为例，假设将最后智能体达到的状态 $s_5$ 作为 hindsight goal，那么第一个hindsight goal transitions为（在hindsight action transitions的基础上） $[initial\ state=s_0,action=s_1,reward=-1,next\ state=s_1,goal=s_5,discount\ rate =gamma]$，而最后一个hindsight goal transitions为 $[initial\ state=s_4,action=s_5,reward=0,next\ state=s_5,goal=s_5,discount\ rate =0]$。

Hindsight goal transitions确保了每隔一个序列的动作，至少会有一个transitions包含稀疏奖励，从而刺激UVFA的critic函数分配更高的Q值给这些包含稀疏奖励的transitions。

### **Subgoal Testing Transitions**

尽管 hindsight action transitions 与 hindsight goal transitions 能够让智能体在稀疏奖励下并行学习各级策略，但hindsight action的定义限制了第 $i$ 层的hindsight action只能是第 $i-1$ 层在 $H$ 个action以内能够达到的状态，这就使得一个层级只能学习到当前状态附近的subgoal action的Q值，而忽略需要超过 $H$ 个动作才能达到的subgoal actions。在这种情况下，很容易让Q函数错误地给被忽略掉的动作空间分配较大的Q值，误导智能体的训练。

为了解决这个问题，作者又设计一种 subgoal testing transitions。**Subgoal testing transitions的作用与hindsight action transitions的作用截然相反**：hindsight action transitions在假设下层策略最优的情况下，学习当前层级策略；而 subgoal testing transitions 则是用于让当前策略理解在当前的低层策略下，一个subgoal状态是否能够被实现。

简单来说，subgoal testing transitions就是当第 $i$ 层提出一个subgoal $a_i$ 之后一部分 $\lambda$ 的时间内，低层级的行为策略必须是当前的低层级策略 $\Pi_{i-1}$ ，即不探索也不最优。如果 $a_i$ 没有在 $H$ 个 $i-1$ 层动作内实现，第 $i$ 层就会收到一个较低的奖励，$penalty=-H$。另外，折扣因子也设为0。

以上图为例，智能体在状态 $s_2$ 时提出了subgoal $g_2$，$H=5$ 个动作（无探索）之后，目标没有被满足，此时的 subgoal testing transitions 为$[initial\ state=s_2,action=g_2,reward=-5,next\ state=s_3,goal=Yellow Flag,discount\ rate =0]$。

Subgoal testing transitions 对不同的Q值有不同的影响，用 $|s-a|$ 表示采用最优低层策略 $\pi_{i-1}^*$ 从 $s$ 到 $a$ 所需要的最低动作步数，不同影响总结如下：

1. $|s-a|>H$：这些转移可以克服 hindsight action transitions 与 hindsight goal transitions 所产生的较远subgoal action被忽略的问题。
2. $|s-a|\le H$ 且能够被 $\Pi_{i-1}$ 实现：这些转移几乎不起作用，因为在只有hindsight action transitions 与 hindsight goal transitions的情况下，这些转移也会被分配Q值。
3. $|s-a|\le H$ 且不能够被 $\Pi_{i-1}$ 实现：这些转移比较复杂，它们的Q值是hindsight action transitions 与 hindsight goal transitions所导致的Q值与subgoal testing transitions所导致的Q值的加权平均，但因为 hindsight action transitions 产生得更频繁（每个subgoal action都会产生）所以，所以占主导地位。

总结来说，subgoal testing transitions克服了只用 hindsight action transitions 与 hindsight goal transitions训练时产生的忽略部分subgoal的Q值的问题。

## **个人思考**

HAC是一种基于subgoals的分层结构，其中的goals有明确的语义：状态空间中较好的状态，因此每个层级的目标就是去寻求好的状态。本文的主要工作是设计了三种不同的transition样本分别用于解决不同的问题：

- **Hindsight action transitions**：解决下层策略变化所导致的非平稳问题；
- **Hindsight goal transitions**：解决奖励稀疏问题；
- **Subgoal Testing Transitions**：解决hindsight action transitions与 hindsight goal transitions所导致的部分subgoalQ值被忽略的问题。

总体来说，本文的工作还是比较grounded的，至少针对每个问题都提出了相应的解决方案，并且有理有据。但是本文所针对的场景貌似比较简单，奖励直接根据目标是否实现来定义，这是否太局限了一些？
